# 从新书继续蒸馏，而不是复制文风

## 1. 接收与定位

登记书名、作者、语言、版本、文件标识、是否扫描、PDF页与印刷页。用户指定版本优先；新版只作为单独来源。先看目录与作者对读者 / 结构的说明，再选有足够上下文的教学单元。

最小样本应包括概念引入、一个从陈述到结论的证明单元、例子或反例、章节或主题的连接方式。若要研究长证明，读完其路线与实际使用的关键引理；不能以目录或几个检索片段推断全文。优先比较同一主题的不同写法，以控制数学难度和读者定位的差别。

有清晰文本层时用搜索定位再连续阅读；公式乱码、图表、扫描或疑似漏页时检查页面图像。只在没有可读图像等替代方法时考虑局部 OCR，人工复核公式，避免整本批量 OCR。

## 2. 抽取的是“决策”，不是形容词

不要只记“作者优雅、语言流畅”。记录能复现的选择，例如“先通过单点情形解释无额外关系，再将需求写成泛性质”；“先指出要控制的导数，再用与 n 无关的界完成一致收敛”。

每条候选规则用以下卡片，不要求卡片全部进入最终正文：

```yaml
rule_id: algebra-universal-property-before-construction
source_id: B-new
locator: "章 / 节 / 定理号；印刷页；PDF页"
read_scope: "实际读过的连续范围"
observation: "作者实际做了什么"
function: "这个选择解决了什么阅读困难"
proposed_rule: "可执行的写作动作"
conditions: "读者先修、文体和数学任务"
counter_use_case: "此规则会徒增负担或误导的场景"
independent_test: "换一个数学题材的新写例子"
status: candidate
```

不用整段摘录代替分析；仅作短引文时明确出处，不拼接原书章节或复刻长证明叙述。

## 3. 处理冲突

先区分数学约定冲突、教学目标差异和审美偏好。不同的张量 / 映射锥约定不能简单投票。面向初学者的动机段与参考书的紧凑陈述可以并存，通过任务路由选择，不强行归一。

某位作者经常使用“显然”不意味着应保留所有“显然”；另一位作者多举例不意味着每个定义必须有例子。保留功能，重写实现。

## 4. 迁移试验

在未被采样的题材上生成原创新写：至少一个短证明和一个含技术瓶颈的证明。先验证数学，再检查可读性。题材最好不与来源的原始段落完全相同，以避免测到记忆或复写能力。

用 `tests/regression.md` 中相同的失败模式作回归：良定义、量词、常数依赖、全局与局部、次数符号、模数与精度、跨格式标签。跨语言和跨格式输出都应与同一数学内容记录核对。

## 5. 晋级与版本

候选规则只有在来源足够、适用边界清楚、迁移无数学损伤时才升为默认规则。一条写法在两个作者中出现也不是效果已证，只说明不是孤例。保留不成功的尝试及停止采用的理由。

v0.1的限制见来源记录。后续可用小版本完善语言、例子或样式；改变数学约定、分支路由或验证逻辑时在变更记录中写明。绝不为了满足“全覆盖”而给未读分支虚构证据。
