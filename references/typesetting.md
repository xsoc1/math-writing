# LaTeX 与 Obsidian 排版规范

下列尺寸、字体和留白是**本项目的可调整默认值**，不是来自学习效果实验，也不是出版社强制标准。期刊、学位论文或用户模板优先。七份书稿提供的是结构与页面实例；我们不原样复制任何一本的版式。

## 1. 页面：安静、清楚、容纳推理

样张采用 A4、左右30mm、上下26mm、约11pt正文。英文用 STIX Two Text 与 STIX Two Math 匹配；中文主体用 Fandol 宋体、标题用黑体，西文和公式仍用 STIX Two。若缺 STIX Two，样式回退到 Latin Modern。字体不打包，使用 TeX 发行版已有资源。

样式将行距集中设置一次：英文约1.08倍基础行距；中文由 CTeX 正常基线再作轻微调整，实际以渲染结果检查为准。不要在 class、setspace、段落和环境四处叠加行距。段落采用首行缩进加少量段间留白，不同时使用很大段距和很大缩进。

标题只建立必要层级。短文通常不超过 section / subsection；更长书稿才考虑 chapter。页眉仅给短标题与版本信息，页脚给页码。正文黑色，线条与强调克制，不给每个定义和公式画彩框。

B5 或其他书页规格适用于长讲义，但应重新检查行宽、长式和图，而不是把 A4 PDF整体缩小。窄版式应重排公式，不能缩小到读不清。

## 2. 定理、定义、证明与引用

同节中的定理、引理、命题、推论、定义、例子和注记共用连续编号，便于顺序查找。英语定理类正文采用数学出版常见的斜体，定义 / 例子 / 注记用正体；中文统一正文正体，靠加粗标题区分。样张用 amsthm、别名计数器及 cleveref 保留正确的引用类型。

陈述应包含自身成立所需的局部条件；跨全文的明确约定可以引用。证明紧跟结果或明确标明后置位置，不能只留下“证明略”而又宣称自足。

LaTeX 使用语义标签，如 `thm:quotient-factorization`、`eq:cauchy-transfer`。引用用 `\cref` 或 `\eqref`，不手打“定理3.7”。重要并会被回引的公式编号，纯中间计算不必逐行编号。

## 3. 数学公式

| 需求 | LaTeX | Obsidian 默认 |
|---|---|---|
| 行内 | `\(...\)` 或项目现有 `$...$` | `$...$` |
| 独立公式 | `\[...\]`、`equation`、`align` | 单独两行 `$$` 包围内容 |
| 多行推导 | `align` / `aligned`，按关系符对齐 | `$$` 内用 `aligned` |
| 定理结构 | `amsthm` 语义环境 | 标题 / 粗体名称，或自定义 callout |
| 引用 | `label` + `cref` / `eqref` | 标题或稳定块 ID 的原生链接 |
| 交换图 | `tikz-cd` | 发布用 SVG/PDF，加关系说明；不粘贴环境 |
| 自定义宏 | 小而明确的宏文件 | 默认展开为 MathJax 已支持的基础表达 |

使用 `\operatorname{Hom}`、`\operatorname{im}` 或 LaTeX 的 `\DeclareMathOperator`，不把多字母算子排成一串变量。使用 `\colon` 区分映射说明，绝对值、范数、集合条件使用清楚的分隔符。不要重定义 `\H`、`\P` 等已有命令来省几个字母。

长式按推理结构换行，通常在等号或不等号处对齐。只对必要片段调整括号大小；不要给所有括号套 `\left` / `\right`，也不要用 `eqnarray`、长串手动空格或 `resizebox` 修理整段数学。

公式属于句子，必要时带逗号或句号；在中英正文中采用各自一致的语法。display 不是一律无标点的海报。

## 4. 图表必须是数学的一部分

图中说明对象、箭头和必要方向；图注解释读者应看见的关系。交换图另用一句文字给出关键等式，确保图不可见时核心逻辑仍可读。数学图用矢量输出且保留源文件，粗细、字体应与正文接近。

TikZ-cd 适合交换图；Mermaid 可用于阅读依赖或流程，不把其一般流程箭头冒充精确的交换图语法。几何图必须核对方向、相交 / 不相交、开闭边界等数学含义。复杂图允许独立浮动，但不能使解释与图相隔数页。

样张中的商模图保留 `f = \bar f\circ q` 的文字与公式说明。SVG由已编译的图导出，不是从教材复制。

## 5. Obsidian：以阅读为主，不把全文做成卡片墙

使用核心 Markdown + MathJax + 内部链接，不要求社区插件。每个笔记的 YAML 可以包括 `language`、`branch`、`prerequisites`、`sources`、`status` 和 `cssclasses`，按需删减。状态如 draft / reviewed 是作者工作状态，不意味着形式化证明完成。

CSS 只作用于 `math-note`，采用主题已有前景色和背景色，兼顾亮 / 暗主题。建议屏幕字体18px左右、行高约1.7、正文最大宽度约46rem；这些只是起点，跟随屏幕与阅读偏好调整。显示公式可以横向滚动，不能裁掉右侧；小屏不强制固定宽度。

主要定理不折叠，证明以普通段落保留。只有可选提示 / 答案使用折叠 callout。自定义 `[!theorem]` / `[!definition]` 的视觉样式来自 CSS，不代表 Obsidian 自带这些数学语义或计数功能；关闭 CSS 后仍有可读的标题和正文。

块 ID 选 ASCII 字母、数字与连字符，如 `^thm-quotient-factorization`。链接示例：`[[Specimen-zh#^thm-quotient-factorization|商模因子化]]`。ID放在被引用块之后并按原生语法留空行；不要用 LaTeX 的冒号 ID 直接替代。按数学单元建笔记，保留来源和假设，而非把每行推导拆开。

## 6. 双格式不等于任意源代码通用

MathJax 只实现 TeX / LaTeX 的相关数学功能，不是完整排版引擎（W10）。在线最新版 MathJax 的能力不证明当前 Obsidian 内嵌的是同一版本。不得默认依赖 amsthm、tikz-cd、cleveref、任意宏包、跨笔记宏状态或自动计数。

Pandoc 的中间表示并不保留所有源格式能力（W13）。只对已声明的 Markdown 子集承诺转换；callout、wikilink、块 ID、引用与复杂图要有显式映射或人工处理。不要对现有 vault 宣称“一条命令生成完美论文”。本包的中英样张使用同一数学内容分别编写，**没有实现通用双向转换器**。

## 7. 最后看成品，而不是只看源码

LaTeX：编译直到交叉引用稳定；检查 missing character、undefined reference、错误与 overfull box；逐页渲染检查行距、页底、符号、图及长式。日志无错误不意味着没有视觉问题。

Obsidian：需在阅读视图和实时预览分别查看，检查窄窗口、亮暗主题、CSS关闭后的可读性、独立打开笔记时的数学渲染及块链接。没有原生运行环境就标为未验证，不用 HTML截图冒充 Obsidian 实测。本包的实际范围见验证报告。
