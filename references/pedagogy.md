# 数学教学与写作模式

入门讲义的操作性要求另见 `intro-lecture.md`，此文件保留证据分层和一般教学原则。长讲义不能只读取本文件后仍以摘要模式执行。

## 证据分层

**教材观察**说明这些书怎么写，不自动证明“这么写学得更好”。**专家建议**提供经验判断。**教育研究**需要保留研究对象、任务及测量范围。**本项目选择**是可检验的设计，不假装有实验背书。下列 W 编号对应 `web-sources.md`。

Knuth、Larrabee、Roberts 的写作讲义（W01）强调用连贯语言解释公式、定义符号并考虑读者；Tao（W02）明确写作因作者、主题、读者与媒介而异。这些是专家指导，支持条件式规则，不支持把某个句长或结构规定为普遍最优。

Hodds、Alcock、Inglis（2014，W03）的公开摘要报告了三个自我解释训练实验，训练注意数学证明的逻辑关系，报告证明理解改善。本轮读取的是研究摘要与书目信息，未复核完整实验材料；不据此宣称对所有水平、所有分支或此 skill 有同等增益。

Mejia-Ramos 等（2012，W04）的公开摘要提出多维证明理解：不仅是句意、逻辑地位和逐步推理，还包括高层思想、组成模块、所用方法与具体例子的联系。这是评估模型，不能表述为本 skill 的随机实验效果。

Tall–Vinner（1981，W05）的概念形象 / 概念定义区分为“形式定义与直观可能错位”提供理论视角。本轮阅读文章开头的理论阐述，不声称逐项复核全文案例，也不从中推出固定的例子数量。

## 按任务选择解释模式

| 模式 | 正文安排 | 应保留的学习动作 | 不应做什么 |
|---|---|---|---|
| 初次接触概念 | 具体需求或熟悉例子 → 精确定义 → 辨识新对象 | 一次说明为什么需要条件，必要时给非例 | 没有对象就先给一页抽象公理；或只留比喻 |
| 学习证明方法 | 目标 → 关键化归 / 长证明路线 → 完整论证 | 解释“此步为什么允许”“这个构造用在哪里” | 把每行都扩写成问答，打断主线 |
| 自学笔记 | 先修与来源 → 可独立阅读的核心单元 → 关联 | 一道针对瓶颈的自我解释题；可选分层提示 | 核心证明默认折叠；拆碎推理依赖 |
| 研究或专题说明 | 问题与贡献范围 → 精确结果 → 组织好的证明 | 指明与已知结果的关系及真正新步骤 | 凭空补历史、意义或文献；教学铺垫淹没主题 |
| 参考型笔记 | 对象 / 约定 → 结果 → 必要条件与定位 | 方便检索和辨别适用范围 | 把“简明”变成无条件结论或只有公式 |

这些是可选安排，不是必须出现的五套标题。短证明可以一段完成；较长自学材料才需要更多层次。

## 最有价值的提示写在哪里

优先放在一个非平凡转折旁：为何有这个候选映射？为何必须先固定紧集？这个常数可依赖半径吗？为何需要在所有坐标图上相容？为什么一次提升还不是完整存在性定理？

在讲义正文中直接给必要解释；在练习中可把提示分为“指出目标—建议工具—局部计算—完整解答”。层数按实际需要，不强制四层。默认折叠只适用于自选提示或答案，不能掩盖定理条件与主证明。

自我解释题的目标是识别逻辑关系，而不是要求学生复述作者原话。“解释使用紧性的那一步”比“你是否理解了？”更可判定。

## 例子需要多样而不是奇特

识别型例子帮助读者辨认定义；计算型例子展示如何使用；非例排除特定误解；跨领域例子说明结构能迁移。选择需要的功能即可。抽象代数可将元素构造和泛性质并列；分析可让参数变化展示“一致”的含义；几何可用坐标模型解释不变量。不给每条定义机械配一整页例子。

## 两层验收：先真，再可读

第一层是数学底线：命题成立、条件完整、证明无跳跃、记号有类型、证据可定位。任一实质失败都阻止交付为“完成证明”。

第二层是读者任务：能否说出目标及先修？能否指出证明最重要的转折？能否解释条件用在何处？能否在一个不同但相近的例子中应用同一机制？这些问题受 W04 启发，本包的题目与评分规则是自拟，未声称经过量表验证。

不要只用字数、公式密度、禁词数量或模型自行打分衡量可读性。缩短文字但使读者来回寻找定义，可能更难读。

## 如何验证下一轮改进

取同一数学内容的旧稿和改稿，保持结论、读者先修与允许知识相同。让独立审阅者先检查逻辑等价，再让目标读者完成“解释关键步、定位条件、迁移到新例”三类任务；记录误解和需要回看的位置。阅读时间可辅助，但不能将读得快等同于理解深。先进行小规模试用，不声称未经执行的提升百分比。
