# 按论证特点选择写法

这里的 B 编号指 `source-observations.md` 中的书稿。各项是由样本启发的工作规则，不是对整个数学分支的唯一写法。路由依据是当前段落的证明负担，不能只看章节名称。

## 1. 代数与范畴：解释构造的任务和它保留的结构

**取样依据：B1 §6.5，B3 II.§5。** 有效主线常为“想解决的映射问题 → 小例子 → 泛性质 → 存在构造 → 函子性 / 实际使用”。不要只写“定义一个商，再验证性质”，应让商关系与目标性质对应起来。也不要先抛出一页范畴语言，再迟迟不给它的用途。

对泛性质分别写清输入对象、结构态射、量词范围、唯一的中介态射和交换关系。泛性质给出的是带结构的对象的唯一性；声称“唯一同构”时限定为与指定结构相容的同构，而非对象的所有自同构都唯一。

构造含代表元时，先解释为何候选映射被迫如此定义，再检验其良定义性。核、像、商、张量积须带着相关映射一起看。元素计算在模范畴中很有用，但不能未经说明搬到任意范畴。

**细节优先级：** 基础环是否交换 / 含幺；左模、右模或双模；映射是集合函数还是同态；定义存在与唯一是否分开；基是否被选择；同构是否自然。

**压缩边界：** 若已熟悉线性映射，可以压缩加法与纯量乘法验证；不能压缩商映射代表元无关性的关键一步。样张：商模因子化。

## 2. 同调代数：把符号预算放在次数和交换关系上

**取样依据：B2 §3.3。** 先声明链 / 上链约定、微分方向和平移符号。随后尽早用一个低次数对象解释抽象构造，再进入矩阵 / 图表计算。最后说明它表达的是何种核、余核、同伦或导出层次的关系。

本样本采用上链约定：微分升一次，`X[1]^n=X^{n+1}`，平移后微分取负。映射锥项顺序是 `X[1] ⊕ Y`。另一本书用 `Y ⊕ X[1]` 并不自动构成错误；切换时同时转换矩阵、嵌入、投影和符号，不能只换对象顺序。

每个矩阵条目标明来自哪一项、进入哪一项。写“是复形”至少核对关键非对角项为什么为零；写“图交换”区分严格相等、在同伦范畴相等或指定一个同伦。全复形还要注明直和 / 直积以及有限性或有界性假设。

**细节优先级：** 上下标、移位、负号、函子的方差、所在范畴、自然变换的分量。**不应省略：** 关系成立的层次及额外的同伦数据。样张：映射锥微分平方为零。

## 3. 分析与复分析：让估计明确服务于目标

**取样依据：B5 第2章 §4；B4 的 Sard 证明也有分析型步骤。** 先告诉读者要控制哪个量、在哪个区域、对哪些变量一致。关键表达式之后解释估计为何足够，再做极限或紧性提取。计算过程不是越长越严谨；不等式的依赖关系比重复代数化简重要。

写 `C` 时交代与后续趋于极限的参数是否无关。选择顺序可写成“先固定紧集 K，再取距离边界的正余量，最后选择与点无关的 N”。每次换序注明可用依据，如局部一致收敛、控制收敛或适用的 Fubini 定理，并检查其条件。

复分析额外关注积分路径及方向、分支与定义域、圆盘闭包是否仍包含在全纯区域内。两参数极限要说明先后或联合控制，不在一行中随意混用。

**反例用途：** 用一个恰好击中误解的例子区分逐点 / 一致、局部 / 全局或实 / 复可微，而非铺满怪异函数。**压缩边界：** 可略机械估计的中间行，不可略控制常数的参数依赖。样张：Cauchy 估计将边界误差传到内部导数。

## 4. 几何与拓扑：让图、局部模型与不变量互相解释

**取样依据：B4 §1、§3、§4。** 先说明对象的几何任务，再给可计算的局部模型，随后检查选择无关性或将局部性质提升为全局结论。必要时采用明确较窄的设定，例如先讨论嵌入 Euclidean 空间的光滑流形；这种缩小范围必须在陈述中说明。

图应该表达一件事：邻域如何对应、路径如何变形、哪条箭头是导数或边界怎样出现。正文中给出相应定义、计算或引用，不能用一幅“看起来如此”的图证明一般性结论。图表需有足够的标签，但不必每个定理都配图。

**细节优先级：** 维数、紧性、连通性、是否有边界、光滑阶数、定向、正则值 / 横截性；构造是否依赖坐标和局部选择。需要拼接时给出相容性，不能止于一张坐标图。

技术长证明可以像 Sard 的样本一样先给分步结构。几何不是一律少计算，抽象也不是一律不用图。样张：正则水平集的切空间，由曲线求导和维数比较得到等式。

## 5. Lie 理论与表示：写清不同语言之间的接口

**取样依据：B6 导言、§1、§13；v0.2 增补依据为李代数讲义修订案例。** 先根据读者与任务选择路线，不把 Lie 群背景当作纯代数入门的必修先导。

纯代数入门可从矩阵交换子与低维例子开始，经子代数、理想、同态、商、表示、共同权进入结构或生成元关系。根、余根、向量、函数和算子的区别，应在具体计算中建立；首次使用自由对象、张量字、分次和递归作用时先定义并展示操作。

研究群与代数的接口时，再使用“连续对称的对象 → 局部线性化 → 可计算模型 → 结构结论”的路线。抽象定理可紧跟基底或矩阵版本，再说明实际推论；但这不是把群、流形、向量空间和代数当作同一种对象。

群同态的微分、群表示的微分、指数映射及从 Lie 代数反向积分时，分别核对实 / 复、连通 / 单连通等条件。不要从一个局部线性化公式断言全局群由 Lie 代数唯一决定。

PBW 样本提醒：关联分次代数同构、滤过向量空间同构和代数同构不同；对称化要求的特征条件、选择基引出的非典范映射也应保留。给出矩阵例子是为了展示结构，不能用一个矩阵类证明全部抽象情形。

样张：矩阵共轭的微分给出交换子；圆上的指数映射提醒局部信息不等于全局单射性。

## 6. 数论与算术：把精炼建立在明确的算术环境上

**取样依据：B7 II.§§1–2、VII.§1；B1 第10章仅作主题边界参考。** 常用路线为“指定域与归一化 → 小引理 → 不变量 / 局部判据 → 主结果 → 实算与例外”。这种精炼适合已有背景的读者；初见 p-进对象时仍需说明相容剩余类与极限的关系。

每次切换 Z、Q、Z_p、Q_p、F_q 都写清。绝对值 / 赋值归一化须固定；区分元素、剩余类和代表元；明确模数与精度。把 p=2 或特征2单列，仅当当前命题确有例外，不机械地在所有命题后加“p≠2”。

局部—整体结论必须限定为所用定理允许的对象，不能从二次型推广到任意方程。一次提升是有限精度事实，完整 p-进存在性还需要迭代、相容与收敛论证。

样张：简单根的一步提升；用多项式展开说明余项为何消失在所需模数下。

## 混合分支与未覆盖分支

给论证片段而不是整篇文章贴标签。例如模形式基本域需要算术条件、群作用与几何图示；紧 Lie 群的积分需要分析的换序条件；同调构造遇到拓扑实现时加入几何的连续性与拼接要求。

概率、PDE、数值分析、组合、逻辑等尚无充分的专门取样。暂只应用通用的对象、条件、推理与可读性规则；新增分支需要专门语料和至少两个不同题材的迁移检验。不要把本包经验直接包装成这些领域的成熟风格指南。
