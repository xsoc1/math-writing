## 编译提示没有被隐藏

mathtools 与 unicode-math 共同使用时，日志保留关于 overbracket / underbracket 和若干冒号命令优先级的两类兼容性提示。样张未使用那些存在差别的命令，已检查相关页面；这里不报告“零警告”。独立图形编译还提示 shell-escape 已关闭，这是本包预期设置。

## 没有做的测试

没有在真实 Obsidian 应用中测试阅读视图、实时预览、主题、插件、CSS选择器和块链接跳转。独立 MathJax 公式转换**不能替代**这些原生测试。

没有运行 VS Code GUI、Zotero / Better BibTeX 自动同步或 Biber 文献链；它们是已调研的可选工具模式。没有实现、测试任意 Markdown 与 LaTeX 的双向无损转换。

本机实际编译使用 XeTeX、latexmk 4.86 与 CTeX 2.5.10。未做 Windows、LuaLaTeX 或缺字体回退分支的完整跨平台回归。核心Python脚本使用标准库；公式检查是依赖Node和已安装mathjax-full的可选步骤。

没有对七份书稿逐页精读，也没有用真实读者开展教学效果实验。`tests/regression.md` 给出的是后续语义任务及预期行为，不得将它当作本轮模型测试通过率。

## 采用后的最小复核

先在测试目录或测试 vault 打开样张。核对本机字体、一个长公式、一处交换图、一个块链接以及CSS关闭后的显示。然后再将需要的模板和配置合并到实际项目，不覆盖已有设置。
