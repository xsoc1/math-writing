# 使用初版 skill 的工作提示词

请读取本目录的 `SKILL.md`，再按当前主题加载所需的分支、双语和目标格式参考文件。不要一次性把全部规则抄进输出，也不要把我的数学文章写成工作报告。

本次任务是：【新写 / 修改 / 翻译 / 审阅】。
主题与材料：【填写或使用当前已提供的材料】。
读者已知：【列出实际先修，例如线性代数与群环模基础】。
语言：【中文 / 英文 / 双语】。
目标：【LaTeX / Obsidian Markdown / 两者】。
文体：【讲义 / 自学笔记 / 研究说明 / 参考条目】。
变动边界：【例如保持命题与证明方法不变，只调整说明和组织】。

先核对命题、条件、量词、记号和证明依赖。发现数学缺口或不成立的陈述，应具体指出，不能当成润色静默修补；不影响正确性的版式与详略问题可以按 skill 的默认值处理。

围绕当前论证的真正难点安排解释：必要时补动机、关键化归、例子或图的说明，不强制每节套固定结构。中英文各自自然表达，数学含义严格对应。可读性来自减少误解和读者补步骤的负担，不来自删掉条件。

直接交付成文与可用文件。可执行环境存在时编译、检查日志并查看渲染结果；Obsidian不能实际运行时明确未做原生视觉验证。最后只简述重要修改、实际验证及未解决的数学问题。不得虚构读取、运行或测试结果。
