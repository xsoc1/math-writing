# 纳入新书并迭代 skill 的工作提示词

以当前 `math-writing` 包为起点，先读 `SKILL.md`、`references/source-observations.md` 与 `references/distillation.md`，再阅读我新提供的书籍。保留现有有效规则，不为扩大体量而重写整个包。

本轮重点：【分支 / 语言 / 读者 / 特定写作困难】。

登记具体版本，区分 PDF 页码与印刷页码。选读有完整上下文的概念引入、证明和例子 / 非例；扫描及公式乱码处看图像，不根据目录推断整章。来源没有支持的观察明确标为暂定，不把你的设计冒充作者做法。

提炼可执行的写作决策，给出适用条件与反向场景。比较新来源与原有规则：是数学约定不同、读者不同，还是确实值得改进？发生冲突时采用条件路由，不平均作者文风，不按作者人数投票决定数学约定。

用不同于来源段落的新题材测试新增规则。先审数学，再审中文 / 英文的自然表达，最后检查 LaTeX 与 Obsidian 的语义和展示。不要复写原书长段内容，不把未采样分支填成成熟规范。

完成后实际修改需要改动的 skill、参考文件、样张与测试，更新版本和来源记录，提供文件与简短变更摘要。区分本轮已做与未做的测试，不使用未经执行的性能提升数字。
