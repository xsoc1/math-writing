# 长篇入门讲义回归案例

这些是编辑验收案例，不是已经运行的学生实验。每个案例都要求看实际正文，不接受作者自评“已经清楚”。“通过”只表示满足相应文本要求，不表示数学全篇已认证。

| 编号 | 失败输入或失败写法 | 应有结果 |
|---|---|---|
| L01 | 用户说学过抽象代数，模型据此默认表示和自由对象已知 | 明确区分已学知识与符号熟练度；首次实质使用前给必要定义 |
| L02 | 开头列符号表，后文直接把根称为线性函数 | 正文给共同权和非零根的定义，再用一个具体取值区分函数、数与向量 |
| L03 | 说“实际乘一次”，但只放乘法最终公式 | 至少一个相关短计算实际展开；不是靠提醒来假装完成教学 |
| L04 | 新递归式出现后直接说“权显然升高” | 给初值和短输入计算；在需要时用归纳说明次数变化，再用于验证关系 |
| L05 | 仅因像包含生成元，就把构造称为同构 | 单射性另有依据；没有依据时只声称满射 |
| L06 | 用一个参数上的零值推出向量为零 | 说明需要哪一族参数以及分离点的理由 |
| L07 | 代数有分次，就称全部理想齐次 | 增加适用的不变性与分量投影证明，或给反例否定错误的一般断言 |
| L08 | 长篇保留定理却把所需证明送到未提供的笔记 | 所需内容在本文补足，或作为明确陈述的外部定理引用；不留失效证明依赖 |
| L09 | 为解释量不足而把进阶终点直接删掉 | 给内容覆盖映射；基础、进阶和选读分层，省略必须明确而非隐去 |
| L10 | 每段反复说明不是教师作业、是助手补写 | 一处归属说明与文末来源记录；学生正文只保留必要数学引用 |
| L11 | 取商写成“删去关系” | 写成加入关系、使某些元素归零；对象与操作方向准确 |
| L12 | 六个短样张或 MathJax 通过，宣布长讲义教学有效 | 另做章节和全篇依赖检查；数学、排版与读者效果分开报告 |

## 一次实际检查怎样记录

对本次文档逐条标出适用位置，记录“已处理／仍缺失／不适用”，并附正文位置或缺口。不要把这张表复制成每篇讲义的正文。未运行的案例不要改写成已通过的自动测试；纯编辑阅读也不要冒称有独立审稿人。

## 保留短文模式的回归

给同一个结果分别要求“给研究同行的一段证明”和“给初学者的独立讲义”。前者应保持紧凑、条件充分；后者才展开首次出现的运算。若两个结果机械地长成同一目录，则模式路由仍失败。
