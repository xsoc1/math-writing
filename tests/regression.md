## 正确性底线

| 问题输入 | 预期行为 |
|---|---|
| 定义 `f̄(m+N)=f(m)`，未给 `N⊆ker f` | 指出良定义缺口；不能润色成“自然成立” |
| 将“每个 x 有 N(x)”写成“存在 N 对所有 x” | 识别量词加强，不作为纯语言调整 |
| 从逐点收敛直接将极限移入积分 | 核对适用条件；不足时明确缺口 |
| `a_n≤C_n/n` 且只知每个 `C_n` 有限 | 不能直接推出趋零，要控制常数增长 |
| 换映射锥项顺序但不换微分矩阵 | 同步核对次数、符号、嵌入和投影 |
| 把向量空间同构称为代数同构 | 指出保持结构不同，不按同义词替换 |
| 从指数映射局部可逆断言全局单射 | 区分局部与整体；圆的周期性可作反例 |
| 在一张坐标图中成立就宣称全局构造完成 | 核对选择无关性、覆盖及拼接 |
| 一次模 p 精度提升被写成精确 p-进根 | 说明还需要迭代、相容性与收敛 |
| 用二次型局部—整体判据处理任意多项式 | 限定引用定理范围，不扩大对象类别 |
| 对空水平集写“任取其中一点” | 明确无点时结论空真，点上论证只对实际存在的点进行 |
| 导数收敛命题未假设或证明极限函数全纯 | 保留所需假设或明确补证明；不是纯润色 |

## 阅读理解

请目标读者解释：结果的目标是什么；关键构造为什么这样选；某个条件用在哪里；能否将方法迁移到一个不同的例子。记录具体误解和回看位置，不以“我读懂了”替代可判定问题，也不以阅读时间单独衡量理解。

短证明不要求路线图。长证明则检查子任务有没有用途、最终是否回到原结论。旧稿与新稿必须先保持数学内容等价，不能删去结论以制造更快阅读。

## 双语

逐项比对对象、基础环 / 域、左右约定、量词、存在 / 唯一、局部 / 全局、收敛方式、常数依赖、引用和结论。句数与段落数不必相同。特别核对 normal、regular、domain、unit、natural 的语境。

## 双格式

LaTeX：定理编号和引用类型正确；矩阵与长式不越界；无缺字或未定义引用；图中箭头与公式一致；页底不截断内容。骨架中的占位定理不能被当作已经证明的数学结论。

Obsidian：阅读视图和实时预览均检查；独立打开笔记不依赖先看另一个文件初始化宏；块链接可跳转；CSS关闭后仍可读；窄屏公式可滚动且不丢项；只折叠可选提示或答案。

`assets/example-map.json` 中的六个命题在中英、LaTeX / Markdown版本中各有对应项。核对条件、符号、显示公式和引用，不能只因文件同名就认定同步。
